**Antes de reanimar tu formulario**

La foto se procesa con inteligencia artificial en Amazon Web Services para detectar los campos. Se guarda de forma privada y solo se usa para crear tu formulario.

Usa preferiblemente un formulario **en blanco**. Si ya tiene datos personales escritos, tápalos antes de tomar la foto.

Las respuestas que reciba tu formulario solo las puede ver quien tenga el enlace de administración.
